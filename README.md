# lls-cc-mods
Lua Language Service - ComputerCraft - Mod peripheral additions

Intended to be used with: VS Code + Lua Language Service + [Lua Language Server library for CC: Tweaked](https://github.com/nvim-computercraft/lua-ls-cc-tweaked)

Your settings.json (global, profile, or project) will need the path to a copy of this repo added.
e.g.
[`
    "Lua.workspace.library": [
        "C:/LuaThirdParty/cc-tweaked-documentation/library",
        "C:/LuaThirdParty/lls-cc-mods",
    ],
`]
